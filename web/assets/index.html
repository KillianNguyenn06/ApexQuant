Backtest configuration

Daily execution is active. Minute execution is temporarily disabled: long minute histories need disk-backed storage, chunked processing and paged replay before support can be verified. Daily data cannot produce genuine minute candles.

The entry day counts as day one. Stop/target exits take priority; otherwise exit at the deadline's close.

Auto estimates each stock’s price response to the previous bar’s VWAP using up to 252 observations before the run, then keeps the estimate fixed. It requires at least 60 usable observations. Manual overrides estimation with your chosen half-life. A shorter half-life means a stronger pull; neither choice guarantees recovery.

Daily execution uses recent prices for VWAP and both bands. Minute execution uses session VWAP, reset each day.
